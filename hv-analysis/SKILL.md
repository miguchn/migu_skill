# 横纵分析法（HV Analysis）

深度调研方法：纵轴看历史，横轴看竞品，两轴交叉出判断。本质不是堆资料，是**追源**——它从哪来、往哪去、为什么是它而不是别的。

## 流程

1. **定对象**：研究什么 + 为何研究（决策 / 知识储备 / 写稿）。目的决定深度。
2. **收集信息**：优先一手来源（官方资料、原始数据、论文、财报、访谈）；重要结论记录来源与日期；信息不足就用搜索补，不凭模型记忆硬写。
3. **纵轴** → **横轴** → **综合** → **出报告**。

## 纵轴三问

1. **诞生**：什么背景和需求下诞生，关键推动者是谁
2. **演变**：经历了哪些重要转折、成功和失败
3. **路径依赖**：哪些早期选择变成了今天的能力或包袱，如何约束它未来的选择

## 横轴三问

1. **对比对象**：选最值得比的（1-3 个），说明为什么选它们
2. **统一维度**：用同一组维度比较强项、短板、独特性
3. **选择解释**：用户/市场为什么选它，又为什么放弃它

## 综合判断

1. 未来最可能出现的路径（**1-3 条，视情况而定，不凑数**），每条的前提和预警信号

> 路径依赖对未来的约束已在纵轴第 3 问完成，综合阶段不重复问。

## 证据规则（硬规则，不可违反）

1. 优先使用官方资料、原始数据、论文、财报、访谈等一手来源
2. 重要结论就近标注来源与日期
3. 事实、推断、观点分开写
4. 信息冲突时并列呈现；找不到证据时明确写"暂未核实"

## 输出模板

顺序：**核心结论** → 关键时间线 → 横向对比表 → 表外洞察（没有就省略，不重复表里内容）→ 未来判断 → 仍待确认的问题。

深度分级：简单对象 2000-5000 字；复杂对象上限 30000 字。语言通俗，不堆资料。

## 常见跑偏

| 跑偏 | 修正 |
|---|---|
| 堆资料没判断 | 核心结论放最前，所有材料服务结论 |
| 观点当事实 | 证据规则第 3 条：三分离 |
| 凑三条路径 | 路径视情况，一条够就一条 |
| 凭模型记忆写旧数据 | 搜索核实一手来源，标日期 |
| 详细分析复读表格 | 表外只写表里看不出的洞察，没有就省 |
